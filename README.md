# Стоматологическая клиника «Оптимальный выбор»

Прототип нового сайта клиники (главная страница). Статический сайт — HTML/CSS/JS без сборки, готов к размещению на GitHub Pages.

## Структура

- `index.html` — главная страница
- `css/style.css` — стили (палитра из логотипа: зелёный `#57C24E` → синий `#2E80B5`)
- `js/main.js` — анимации, счётчики, мобильное меню, модальное окно записи
- `assets/logo-icon.avif` — логотип
- `_server.js` — локальный сервер для разработки (не нужен для GitHub Pages)

## Локальный запуск

```
node _server.js
```

Сайт откроется на http://localhost:4173

## Публикация на GitHub Pages

1. Создать репозиторий и запушить содержимое этой папки.
2. В настройках репозитория: Settings → Pages → Source: Deploy from a branch → `main` / root.

## Источники контента

Вся информация (услуги, врачи, акции, контакты) взята со старого сайта клиники stomko.ru.

Планируемые разделы многостраничного сайта: Акции, Услуги, Врачи, Цены, Контакты.
